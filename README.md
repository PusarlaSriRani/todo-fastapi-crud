# todo-fastapi-crud
# FastAPI Todo CRUD App

A simple full-stack Todo application built with **FastAPI** and **JavaScript Fetch API**.

## Features

* Create Todo
* Read Todos
* Update Todo (PUT)
* Patch Todo (PATCH)
* Delete Todo
* Styled HTML frontend

## Tech Stack

* **Backend:** FastAPI, Pydantic
* **Frontend:** HTML, CSS, JavaScript
* **Version Control:** Git & GitHub

## Run Backend

```bash
uvicorn app.main:app --reload
```

## Open Frontend

Open `frontend/index.html` using **Live Server** in VS Code.
